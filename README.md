# 과일 요거트 찹쌀떡

하늘에서 떨어지는 과일과 쓰레기를 입을 벌려 먹고, 만들어진 찹쌀떡을 손으로 만지다가 집어서 먹는 브라우저 게임. 자세한 내용은 `SPEC.md`를 보세요.

## 실행 방법

카메라 권한 때문에 파일을 바로 열지 말고 간단한 서버로 열어요.

```
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열고 "시작"을 누르세요.

- 개발 중 임시 입력(`input.js` 첫 버전): 마우스 좌클릭 = 핀치, 스페이스 = 입 열기
- 진짜 입력: 얼굴(입 열기)과 손(엄지·검지 핀치)을 카메라에 보여 주세요.

## 한 판 흐름

1. 시작 화면에서 카메라를 켜고 얼굴과 손이 잡히면 시작
2. 재료 모으기 60초: 입을 벌려 떨어지는 재료를 먹어요
3. 만들고 먹기 최대 30초: 핀치로 떡을 만지고, 집어서 입에 가져가 먹어요
4. 결과: 점수와 칭호가 나와요. "다시 하기"로 처음부터

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html`, `style.css` | 페이지와 화면 UI |
| `main.js` | 게임 루프와 화면 전환 |
| `score.js` | 점수와 칭호 계산 |
| `input.js` | 카메라, 얼굴, 손 인식 |
| `items.js` | 떨어지는 재료와 먹기 판정 |
| `mochi.js` | 찹쌀떡 물리와 렌더 |

## 시연 전 확인

- 발표 환경의 카메라로 한 번 끝까지 돌려 보기
- 손 핀치가 불안정하면 SPEC.md의 "위험과 대비"를 따르기
